Adicionando um novo contrato

Proxies e dispatchers são gerados automaticamente pelo Rpc.SourceGen a partir das interfaces marcadas com [RpcContract]. Esta página mostra os passos pra adicionar um novo contrato e o padrão que o gerador emite.

Cenário: IInventoryService

Vamos criar um contrato que retorna estoque por SKU.

1. Definir a interface e os DTOs

Em Sample.Contracts (ou no seu próprio assembly de contratos — referencia só Rpc.Contracts e Rpc.Core):

using Rpc.Contracts;

namespace Sample.Contracts;

[RpcContract]
public interface IInventoryService
{
    [RpcMethod(1)]
    Task<StockLevel> GetStockAsync(string sku, CancellationToken ct);

    [RpcMethod(2, Exclusive = true)]
    Task<bool> ReserveAsync(string sku, int qty, CancellationToken ct);
}

public sealed record StockLevel(string Sku, int Quantity, DateTimeOffset MeasuredAt);
IDs estáveis: [RpcMethod(N)] é a chave de wire. Use IDs sequenciais e nunca reuse — se você deletar um método, queime o ID. Isso mantém clientes antigos funcionando após deploys de servidor.

2. Compile

O Rpc.SourceGen emite automaticamente, em Sample.Contracts.Generated:

  • InventoryServiceProxy : IInventoryService — serializa args, chama IRpcInvoker.
  • InventoryServiceDispatcher com Register(IDispatcherRegistry, IInventoryService impl) — deserializa payload, chama o impl.
  • Records auxiliares __IInventoryService_{Método}_Args para métodos com 2+ parâmetros.

Pra ver os arquivos gerados em disco, adicione no csproj:

<EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>
<CompilerGeneratedFilesOutputPath>$(BaseIntermediateOutputPath)GeneratedFiles</CompilerGeneratedFilesOutputPath>

Os .g.cs aparecem em obj/GeneratedFiles/Rpc.SourceGen/Rpc.SourceGen.RpcContractGenerator/.

3. Tipos de retorno suportados

RetornoGera proxy chamandoGera dispatcher registrando
Task<T> / ValueTask<T>InvokeAsyncRegisterInvoke
Task / ValueTaskInvokeAsync (ignora resultado)RegisterInvoke (retorna null)
IAsyncEnumerable<T>OpenStreamAsyncRegisterStream
IDuplexCall<TUp, TDown>OpenDuplexAsync + DeferredDuplexCallRegisterDuplex com pumps bidirecionais

4. Implementar o serviço

public sealed class InventoryServiceImpl(IDbContext db) : IInventoryService
{
    public async Task<StockLevel> GetStockAsync(string sku, CancellationToken ct)
    {
        var qty = await db.Stocks.Where(s => s.Sku == sku).Select(s => s.Quantity).FirstOrDefaultAsync(ct);
        return new StockLevel(sku, qty, DateTimeOffset.UtcNow);
    }

    public async Task<IReadOnlyList<StockLevel>> GetStockBatchAsync(IReadOnlyList<string> skus, CancellationToken ct)
    {
        var stocks = await db.Stocks.Where(s => skus.Contains(s.Sku)).ToListAsync(ct);
        return stocks.Select(s => new StockLevel(s.Sku, s.Quantity, DateTimeOffset.UtcNow)).ToList();
    }
}

5. Registrar no host

Server-side (em DispatcherStartup.cs):

public Task StartAsync(CancellationToken cancellationToken)
{
    // ... handlers existentes ...
    InventoryServiceDispatcher.Register(dispatchers, _orderService);  // se for server-side

    proxies.Register(typeof(IInventoryService),
        (inv, addr) => new InventoryServiceProxy(inv, addr));

    return Task.CompletedTask;
}

Agent-side (se o handler vive no agente):

// no Program.cs do agente
builder.Services.AddSingleton<IInventoryService, InventoryServiceImpl>();

builder.Services.AddSingleton<IHostedService>(sp =>
{
    var dispatchers = sp.GetRequiredService<IDispatcherRegistry>();
    InventoryServiceDispatcher.Register(dispatchers, sp.GetRequiredService<IInventoryService>());
    return new NoopHostedService();
});

6. Usar

var inventory = Rpc.For<IInventoryService>(RpcAddress.Server);
var stock = await inventory.GetStockAsync("SKU-001", ct);

Contratos com streaming simples

Para streaming unidirecional servidor → cliente, use IAsyncEnumerable<T>:

[RpcContract]
public interface IPrintJobService
{
    [RpcMethod(1)]
    IAsyncEnumerable<PrintProgress> PrintReportAsync(ReportRequest request, CancellationToken ct);
}

O gerador emite proxy chamando invoker.OpenStreamAsync(...) e dispatcher como async iterator que serializa cada item via JsonSerializer.Serialize.

Versionamento

  • Adicionar campo opcional a um DTO: compatível dos dois lados se o System.Text.Json ignorar membros faltantes (padrão).
  • Adicionar novo método a um contrato: use o próximo ID livre. Clientes antigos simplesmente não chamam.
  • Renomear um método: mantenha o ID do [RpcMethod]. O nome em C# muda, o wire não.
  • Remover um método: queime o ID. Não reutilize esse ID nunca, pra não confundir clientes que ainda chamam.
  • Alterar tipo de retorno: é uma quebra. Crie um [RpcMethod(N+1)] novo e marque o antigo como [Obsolete].
